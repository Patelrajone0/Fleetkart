# Fleetkart

FleetKart is a collective car-buying platform designed to help individual car buyers save more by pooling their purchasing power. By grouping retail buyers looking for similar models or segments, FleetKart negotiates directly with regional authorized dealerships to secure bulk-purchase pricing typically reserved for corporate fleets.

## Features

- **Pan-India Coverage**: Support across all 28 Indian States with cascading city filters.
- **Group Fleets**: Join or create custom car buying fleets with target group sizes.
- **Live Deal Rooms & Chat**: Coordinate with fellow buyers, share dealer quotes, and vote on tenders.
- **Budget Discovery**: Filter and explore vehicles across budget ranges, fuel types, and body styles.
- **Dealer Tenders**: Real-time dealer quotation bids and pass-through volume discounts.
- **Custom Brand Identity**: Integrated vector brand suite with downloadable SVG and PNG assets.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, CSS spring cubic-bezier transitions

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
